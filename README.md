# About Korge Shooter
Korge Shooter is a hardcore multiplayer first-person shooter built on the Unity Engine by developer kirillkorge (kirillkorge2024 on Steam).

Prepare for an ultimate test of survival in fast-paced online matches where there is no room for error—your primary goal is to be the last one standing in the arena. You can create your own lobbies to play with friends, unlock achievements, and explore additional paid content (DLC).
## Game Features:

- Minecraft-inspired arsenal: The weapons in the game are based on the well-known "MrCrayfish's Gun Mod."

- Unique vehicles: Unlike other games in this genre, this title features vehicles (taken from "MrCrayfish's Vehicle Mod") that provide a significant advantage in terms of maneuverability and tactics.
